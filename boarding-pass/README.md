# Посадочные — Android-приложение для посадочных талонов

Хранит посадочные талоны, читает из штрихкода все данные рейса, следит за статусом рейса
и по одной кнопке показывает код на весь экран для сканера у выхода на посадку.

## Возможности

- **Добавление талона**
  - сканирование камерой (PDF417, Aztec, QR, Data Matrix) — с бумаги или с экрана другого телефона;
  - из фото или скриншота в галерее;
  - из файла: PDF (все страницы, несколько пассажиров в одном PDF), картинка, Apple Wallet `.pkpass`;
  - через «Поделиться» / «Открыть с помощью» из почты, мессенджера или приложения авиакомпании.
- **Данные из посадочного** (стандарт IATA BCBP, Resolution 792): пассажир, рейс, авиакомпания,
  дата, аэропорты вылета/прилёта с городом и страной (флаг), место, класс, номер посадки, PNR,
  номер билета, бонусная карта, норма багажа. Многосегментные талоны разбиваются на отдельные рейсы.
- **Статус рейса**: статус (по расписанию / задержка / посадка / вылетел / прибыл / отменён),
  терминал, выход, стойки регистрации, время по плану / ожидаемое / фактическое, лента багажа,
  модель и бортовой номер самолёта.
- **Отслеживание в фоне** с дня до вылета до прилёта и уведомления о смене выхода, терминала,
  времени и статуса.
- **Код на весь экран**: белый фон, максимальная яркость, экран не гаснет, длинный PDF417
  разворачивается вдоль экрана.
- Коды, которые не являются стандартным посадочным, можно сохранить как есть и заполнить рейс вручную.

## Статус рейса: API-ключ

В самом посадочном нет терминала, выхода и типа самолёта — они берутся из онлайн-сервиса.
В настройках выберите один и вставьте свой ключ (у всех есть бесплатный тариф):

| Сервис | Что даёт | Где взять ключ |
|---|---|---|
| AeroDataBox (RapidAPI) | статус, терминал, выход, стойки, лента, модель и борт самолёта | https://rapidapi.com/aedbx-aedbx/api/aerodatabox |
| FlightAware AeroAPI | статус, терминал, выход, тип и борт; данные за ±2 дня | https://www.flightaware.com/aeroapi/portal/ |
| Aviationstack | статус, терминал, выход, задержка, лента; 100 запросов/мес | https://aviationstack.com/signup/free |

## Сборка

APK собирает GitHub Actions (`.github/workflows/boarding-pass.yml`) при каждом пуше в `boarding-pass/`:
готовые файлы лежат в pre-release **boarding-pass-latest** и в артефактах запуска.

Локально (нужны JDK 17 и Android SDK 35):

```bash
cd boarding-pass
./gradlew assembleRelease      # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest    # тесты парсера BCBP и ответов API
```

Сборки подписаны ключом `app/signing/boardingpass.jks` (пароль `boardingpass`), чтобы новые
версии ставились поверх старых без потери данных. Для своего ключа задайте секреты репозитория
`SIGNING_KEYSTORE_BASE64`, `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`;
локально — переменные окружения `SIGNING_STORE_FILE`, `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`,
`SIGNING_KEY_PASSWORD`. При смене ключа приложение придётся переустановить.

## Устройство

- Kotlin, Jetpack Compose (Material 3), CameraX + ML Kit (встроенная модель, работает без Google Play),
  ZXing для запасного распознавания и генерации кода, WorkManager для фонового отслеживания.
- `core/` — чистый Kotlin без Android: парсер BCBP, модели, клиенты API статуса (покрыто unit-тестами).
- Талоны хранятся в JSON-файле только на устройстве.
- Справочники: аэропорты — [OurAirports](https://ourairports.com/data/) (public domain) с часовыми поясами
  из [mwgg/Airports](https://github.com/mwgg/Airports); авиакомпании — [OpenFlights](https://openflights.org/data) (ODbL).
